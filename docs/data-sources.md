# 数据源与约定

所有地址均为示例。默认课表、网站、入口为空；GitHub 用户名与资讯地址为空时停用对应来源。示例事件和条目完全虚构。

## ICS 课表

设置页支持最多 10 个订阅。ICS 必须通过公网 HTTP(S) 的 80 / 443 端口下载，不支持携带用户名、密码、片段的 URL，不支持内网 / localhost / 自定义端口。私有订阅可以使用带路径或查询参数的链接，但应像密码一样保管。

支持 RFC 5545 的折行、时区、重复事件、例外日期、单次调整和取消。底层使用 `icalendar` / `recurring-ical-events`。界面默认中国时区；全天 / 时间未定事件不参加上课倒计时，跨天全天事件使用不包含结束日的标准语义。

不根据节假日自行删除或移动课程；保留来源中的待确认标注。教师和节次按来源备注中的已知格式识别，其他格式仍可在“原始备注”查看。解析范围有限，学期结束后需要更新订阅与学期设置。

已有订阅 URL 不回传前端，保存时留空保留旧链接。新订阅必须提供有效 URL。没有日历写回、OAuth 授权或本地文件直接导入。

## 网站监测与入口

每个监测对象包含 ID、名称、URL、预期状态码数组。例如预期 `[200,302]` 时正常登录跳转不会误报。探测读取响应头，不下载整页、不执行脚本、不自动登录、不跟随跳转。

URL 限制与 ICS 一致，只支持公网标准端口。若站点故意拒绝机器人或对服务器源 IP 限流，面板会显示从该服务器实际获得的结果。

入口是独立的 HTTP(S) 链接集合，允许内网地址与自定义端口；入口不会被后端访问。关联某个公网监测对象后可显示其状态，但不能把这个状态视为局域网链路状态。

## GitHub

用户名配置后每 15 分钟同步一次。最多展示最近推送的 30 个公开仓库，优先排列置顶仓库；版本信息来自前 5 个仓库，公开参与 PR 列表为有界结果，不能视为完整历史归档。

Token 可选，建议使用满足公开只读接口需求的最小权限。Token 只保存在服务端；即使 Token 能访问私人仓库，面板仍过滤私人仓库。

为避免放大请求量，每轮只对最近 1 个（无 Token）或 3 个（有 Token）进行中 PR 补充 CI 与审阅，其他状态显示“未读取”。API 返回限流、访问受限或未知时保留上次结果并标记来源状态。

## AI 资讯 JSON

填写根地址，例如 `https://news.example.com/`。后端读取：

```text
GET /data/index.json
GET /data/YYYY-MM-DD.json
```

索引：

```json
{"dates":["2026-10-28","2026-10-27"]}
```

日期文件：

```json
{
  "date":"2026-10-28",
  "generated_at":"2026-10-28T07:30:00+08:00",
  "categories":[{
    "name":"开源项目",
    "items":[{
      "title":"示例：今天的项目更新",
      "url":"https://example.com/article",
      "source":"示例来源",
      "time":"2026-10-28"
    }]
  }]
}
```

只接收 HTTP(S) 原文链接，按分类与 URL 去重；一日最多保存 300 条。日期必须符合 `YYYY-MM-DD`，采集只保留配置的时间范围。例子见 [examples/news](../examples/news/)；示例日期不是每天自动生成的，搭建自己的发布器时需要写入真实当天日期。

每天中国时间 07:30 触发读取。如果当天未发布、结构无效、条目为空或网络失败，会保留最后一次结果并重试。当天内容可以刷新，已导入历史期次是归档快照，不保证自动追踪历史文件的后续修改。

**没有通用 RSS、任意网页 HTML 抽取或 AI 自动写新闻功能。** 此仓库只消费自己的发布器提供的数据；介绍页演示文字不是真实资讯。
